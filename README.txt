ANIMAL LIFE - AVANCE VISUAL

Esta versión es SOLO PARA PRESENTACIÓN VISUAL.
No utiliza MySQL ni base de datos.

Para usarla en tu XAMPP:
1. Copia la carpeta animal_life_avance_visual dentro de C:\xampp\htdocs\
2. Inicia Apache.
3. Abre:
   http://localhost:81/animal_life_avance_visual/

El login es demostrativo: cualquier correo y contraseña válidos en el formulario permiten pasar al panel porque no existe autenticación real.

Pantallas incluidas:
- Inicio
- Servicios
- Login
- Panel principal
- Usuarios
- Propietarios
- Mascotas
- Solicitudes
- Citas
- Pagos
- Atenciones veterinarias

Esta versión sirve como avance de interfaz/prototipo. La versión con PHP + MySQL se utilizará posteriormente para la implementación funcional.
